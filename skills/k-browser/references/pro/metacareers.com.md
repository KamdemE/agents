# metacareers.com (Meta Careers)

**Category:** Tech careers portal. **Account:** public. **Profile:** `default`.

> Reference sheet for the 3A internship hunt: Meta intern programs.

## Login

None — public.

## Structure / navigation

- **Jobs search:** `metacareers.com/jobs?q=<query>&l=<location>&te=INTERNSHIP` — returns hundreds of internship items
- **Job page:** `metacareers.com/profile/job_details/<id>` — role, location, team, level.

## Key status (2026-09-09)

- **Out of scope for 3A X**: the internship list is nearly all **Research Scientist Intern (PhD)** roles (AI/ML, Security, Vision, FAIR, Alignment...) in Menlo Park/Redmond/Zurich/London — PhD required, US/UK/CH locations.
- No master-level AI internship visible in Paris FR.

## Known quirks

- The `te=INTERNSHIP` filter keeps PhD internships in the list — no BS/MS toggle; filter manually by "PhD" in titles.
- 400 items default — page loads the first batch only; scroll loads more.
