- **Post-boot terminal latency (ISS-20260706-001):** If Ctrl+T takes 20-30s after reboot but works instantly after ~1min, the root cause is `xdg-desktop-portal-gtk.service` racing with the Wayland display. It crashes with `cannot open display:` → systemd retry cascade → session bus saturated → D-Bus activation of `gnome-terminal-server` blocked. Fix: (1) systemd drop-in `ExecStartPre` that waits for `org.gnome.Shell` D-Bus before portal-gtk starts; (2) pre-terminal service that starts `gnome-terminal-server` after display is ready. Mitigation: the shell startup (oh-my-zsh at ~1.5s) is unrelated to this bottleneck.

- **OpenCode Extension Hooks (State Leakage & New Session Payload):** When writing hooks for OpenCode (e.g., `messages.transform`), **never use global module-level variables** (`let _agent = null;`). Extension modules are cached, meaning global variables leak across all parallel requests, sessions, and agents, causing severe cross-agent pollution. Furthermore, on the very first turn of a _new_ session, OpenCode user messages do **not** contain `msg.info.agent`. Hooks relying solely on `msg.info.agent` will silently fail on new sessions. Fix: Always use a dynamic, stateless fallback that checks the incoming `_input` payload (`_input.agent` or JSON string inclusion of `"agent":"Target"`/`"You are Target"`) and iterates over an extensible `_TARGET_AGENTS` array.
