4. Log ride + quick note in Cyclers (distance, mood 1–5).

## Daily Home Stack (Sun–Fri only · Sat = vélo)

**Total time:** ~10–15 min · **Mindset:** rhythm + self-love · **Started:** 2026-05-24 (Sun, push day).

### Fixed sequence (6 days / week)

```
100 corde
    ↓
PONT : 20 pompes (jour PAIR)  OU  gainage 1 min (jour IMPAIR)
    ↓
100 corde
```

| Step | Rule |
| --- | --- |
| **Jour pair** (0, 2, 4…) | **20 push-ups** between ropes (knee push-ups OK if needed) |
| **Jour impair** (1, 3, 5…) | **1 min gainage** total between ropes (see rotation below) |
| **Samedi** | **No stack** — vélo + Leclerc only |
| **Option** | +20 **butterfly toe-touch** after ropes when energy allows (2025 habit) |

Stop if shins hurt → walk 15 min instead of rope; keep pont if OK.

### Gainage 1 min — odd-day rotation (month 1)

Keep **one minute total**; switch variant by weekday:

| Impair day | Move | How to fill 60 s |
| --- | --- | --- |
| **Mon** | Plank | 2 × 30 s (knees OK) · [GIF](https://giphy.com/gifs/core-exercises-plank-Rqn2jP5vJNebJ8nHqy) |
| **Wed** | Dead bug | Slow · ~8/side until 60 s · [GIF](https://giphy.com/gifs/CROSSFITBORAN-deadbug-aIyZ9Ra6pyo5ZOHQsm) |
| **Fri** | Side plank | 2 × 15 s/side + 30 s front plank · [search](https://giphy.com/explore/side-plank) |

### Push-ups (pair days)

| Rule | Detail |
| --- | --- |
| **Month 1 dose** | **20 reps** / session (one set between ropes) |
| **Form** | Full ROM or knees; stop 1–2 reps before ugly break |
| **After 4 weeks** | Reassess: hold 20, or add 2nd set of 10, or slow tempo |

### Optional abs — butterfly toe-touch

On back, soles together, hands toward feet — **20 reps** or **2×10** if back peels off mat.
