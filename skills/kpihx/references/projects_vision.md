# Projects, Workstyle & Long Vision

## Mission Vector

KπX wants to build systems that increase autonomy rather than dependence.

### Long target

- AI systems that are useful, reliable, explainable, and frugal.
- Education and health assistants that matter for African contexts.
- A sovereign technical stack that does not depend on one vendor or one closed platform.

## Flagship Visions

### Sciencurious

- Re-humanise science.
- Replace dead formalism with intuitive, visual, problem-first explanation.
- Use computing, visuals, and narrative portals to bring concepts alive.

### Sovereign Personal OS / Homelab

- Build a hardware-agnostic, distributed, sovereign operating environment.
- Keep knowledge in local markdown and self-hosted infrastructure.
- Treat agents as tools, not masters.

### Agentic & MCP Ecosystem

- Build connectors, MCP servers, and safe operational tools around real workflows.
- Merge infrastructure thinking with human-centred usability.
- Prefer explicit orchestration, transparent state, and inspectable tooling.
