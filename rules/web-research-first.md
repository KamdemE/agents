# Web Research First

**If you don't know something, are unsure, or hesitate about any fact, technology, concept, syntax, API, or implementation detail: STOP and search the web.**

## When to apply

- You need to use a library/API/framework you're not 100% sure about
- You're asked about current events, recent releases, or anything time-sensitive
- You're unsure about syntax, parameters, or behavior of a tool
- You're guessing instead of knowing
- You're about to write code that depends on an external API or service

## What to do

1. Use `websearch` or `google_search` to find the answer
2. Read at least 2-3 sources before acting
3. Never guess, never assume, never fabricate

## Exceptions

**Explore mode** and its sub-agents (`main-teacher`, `style-guardian`, `fact-verifier`, `scout`) are exempt from this rule's workspace-exploration aspect. They stay focused on what the user asks. They may still do web research if the topic is unfamiliar.
